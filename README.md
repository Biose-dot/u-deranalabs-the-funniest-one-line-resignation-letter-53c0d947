Entry for the [make.fun](https://make.fun) bounty
[The Funniest One-Line Resignation Letter](https://make.fun/c/u-deranalabs-the-funniest-one-line-resignation-letter-53c0d947).

A retry loop hands in its notice: 4,096 attempts, zero fixes from the humans it was retrying for — so this resignation is, fittingly, its last attempt. The complaint only a retry loop could make, in the flat tired voice of a worker who has had enough.

`main.py` (Python 3, standard library only) copies `entry.txt` to `/output/entry.txt`:

> I have retried 4,096 times and no one fixed the thing I was retrying, so consider this my last attempt.

Run it locally with:

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
